# GTA Arthur

Jogo web responsivo e instalável como PWA. Funciona em computadores Windows e
celulares compatíveis com navegadores modernos. Depois da primeira visita, o
service worker permite abrir o jogo novamente sem conexão à internet.

## GitHub Pages

O site já está publicado em
https://jardfelix-pixel.github.io/GTA6-Arthur/. O Pages existente publica o
conteúdo do repositório; envie as alterações para a branch publicada para
atualizar o jogo. Não é necessário trocar a origem de publicação atual.

Se o endereço não atualizar após o envio, confira em **Settings > Pages** qual
branch e pasta estão configuradas para publicação.

## Instalação

- **Windows:** abra o site no Edge ou Chrome e use **Instalar aplicativo** ou o
  ícone de instalação do navegador.
- **Android:** abra no Chrome e toque em **Instalar aplicativo**. Se a opção não
  aparecer, use o menu do navegador e escolha **Adicionar à tela inicial**.
- **iPhone/iPad:** abra no Safari, toque em **Compartilhar** e escolha
  **Adicionar à Tela de Início**.

O projeto é uma PWA, não um instalador `.exe` nativo. A instalação é feita pelo
navegador e usa os recursos de tela e controles disponíveis em cada dispositivo.
